# План пользовательской документации Messenger

Документация описывает возможности приложения с точки зрения конечного пользователя, сгруппированные по областям. Каждая область — отдельный раздел с подразделами по конкретным функциям.

---

## 1. Вход и учётная запись

### 1.1 Регистрация
- Регистрация по логину и паролю (правила: логин 3–50 символов, буквы/цифры/подчёркивание; пароль от 6 символов).
- Регистрация через Google.
- Регистрация через Yandex.

### 1.2 Вход
- Вход по логину и паролю.
- Вход через Google / Yandex (OAuth).
- Сообщение «только OAuth» для аккаунтов без пароля.

### 1.3 Выход
- Выход из аккаунта.

---

## 2. Профиль и настройки

### 2.1 Личные данные
- Отображаемое имя (display name).
- Статус (необязательный текст).
- Аватар: загрузка, обрезка, удаление (форматы и ограничение размера).
- Видимость в контактах: вкл/выкл (если выкл — не показываться в списке контактов и поиске; чат могут начать только те, у кого уже есть беседа).

### 2.2 Аутентификация
- Логин (изменение при необходимости, правила).
- Установка/смена пароля (текущий пароль для смены).
- OAuth-коннекторы: привязка и отвязка Google / Yandex (несколько способов входа).

### 2.3 Уведомления
- Включение/выключение уведомлений о новых сообщениях (в контексте push и настроек по беседам).
- Разрешения браузера для push (HTTPS, блокировки в Edge и др.).

### 2.4 Режим обновления чата
- Режим «по запросу» (polling) — когда WebSocket недоступен или отключён.

### 2.5 Защита данных и конфиденциальность (профиль)
- Удаление истории: замена автора на «неизвестный автор» во всех сообщениях (необратимо).
- Удаление аккаунта: полное удаление данных (профиль, беседы, сообщения), подтверждение паролем.

## 3. Переписка

### 3.1 Типы бесед
- **Личный чат (1-на-1)** — с одним собеседником.
- **Групповой чат** — группа с названием, участники, роли (администратор / участник).
- **Внешний звонок** — беседа только для звонка по ссылке (аудио/видео), без переписки; участники по ссылке (с аккаунтом или гость).

### 3.2 Список чатов и контакты
- Вкладки: «Чаты» и «Контакты».
- Поиск по чатам.
- Поиск по контактам.
- Кнопка «Новый чат»: выбор «приватный / группа / внешний звонок», поиск по имени (2+ символа), выбор из контактов.
- Создание группы: название, добавление участников.
- Создание внешнего звонка: название (необязательно), получение ссылки для приглашения.

### 3.3 Отправка сообщений
- Текстовые сообщения.
- Вложения: файлы и изображения (ограничения типов и размера).
- Стикеры (из панели стикеров и эмодзи; сохранение в стикеры из сообщений).
- Ответ на сообщение (reply): цитирование и переход к исходному сообщению.
- Пересылка сообщений: выбор одного или нескольких, выбор чата для пересылки.
- Превью ссылок: автоматическое получение title, description, image по Open Graph/meta для ссылок в сообщениях.

### 3.4 Типы контента в ленте
- Текст.
- Изображение (просмотр, увеличение/уменьшение, скачивание).
- Файл (имя, скачивание).
- Стикер (в т.ч. анимированные).
- Сообщение о звонке (длительность, участники, «перейти к сообщению»).

### 3.5 Реакции на сообщения
- Постановка и снятие реакций (эмодзи) на сообщения.
- Отображение реакций (сгруппировано по эмодзи, кто поставил).
- Счётчик «неувиденных» реакций на свои сообщения и сброс при просмотре.

### 3.6 Прочтения и доставка
- Статусы: отправлено, доставлено, прочитано (галочки/индикаторы).
- Счётчик непрочитанных по беседе; отметка прочитанным при просмотре (в т.ч. при прокрутке до сообщения).

### 3.7 Управление беседой и сообщениями
- Информация о беседе: название, тип, участники, роли.
- Участники группы: список, добавление (только админ), удаление участника / выход из группы (leave).
- Удаление беседы: «скрыть у себя» или «удалить для всех» (с пояснением).
- Удаление сообщений: только свои; удаление выбранных (несколько).
- Действия с сообщением: ответ, переслать, реакция, удалить, открыть профиль автора.

### 3.8 Приглашение в беседу по ссылке
- Присоединение к беседе (в т.ч. группе) по ссылке-приглашению (join-conversation.php?token=…).
- Требование входа для присоединения; после входа — добавление в участники.

## 4. Звонки

### 4.1 Звонки 1-на-1
- Инициация голосового или видео-звонка из чата.
- Входящий звонок: принять / отклонить.
- В ходе звонка: микрофон вкл/выкл, камера вкл/выкл, смена камеры (если несколько), завершение звонка.
- Запись звонка (если включено): только аудио или аудио+видео; сохранение на устройство после остановки.

### 4.2 Групповые звонки
- Старт группового голосового или видео-звонка в чате (группа или личный).
- Уведомление «групповой звонок идёт» и кнопка «Присоединиться».
- Участники: список, приглашение по контактам и по ссылке.
- Ссылка на звонок: создание, срок действия (1 ч / 24 ч / 7 дней), копирование, отзыв.
- В звонке: микрофон, камера, демонстрация экрана, запись (если доступно), «покинуть звонок» / «завершить для всех» (для инициатора).
- Гости по ссылке: вход без аккаунта (имя), только аудио/видео; ограничения (например, нет переписки во внешнем звонке).

### 4.3 Внешний звонок (только по ссылке)
- Создание «внешнего звонка»: беседа без переписки, только ссылка для присоединения.
- Участники: с аккаунтом (вход) или гость (имя).
- Пояснение: «аудио/видео по ссылке, переписка недоступна».

### 4.4 Страница «Присоединиться к звонку»
- Переход по ссылке (join-call.php?token=…).
- Проверка ссылки; при истечении или неверном токене — сообщение об ошибке.
- Варианты: войти в аккаунт и присоединиться или указать имя и войти как гость.
- После присоединения — переход в интерфейс звонка (микрофон, камера, демонстрация экрана и т.д.).

### 4.5 Общие элементы звонков
- Минимизация/развёртывание окна звонка.
- Баннер «Идёт запись» и кто записывает.
- Сообщения об ошибках: нет доступа к камере/микрофону, устройство занято, ошибка сети/WebSocket.

## 5. Защита конфиденциальности и E2EE

### 5.1 Сквозное шифрование (E2EE)
- Включение E2EE в беседе; индикация «беседа защищена E2EE».
- Сообщения при недоступном ключе: «[Сообщение зашифровано, ключ недоступен]».

### 5.2 Ключи и разблокировка
- Разблокировка чатов при открытии приложения: ввод PIN и/или биометрия (отпечаток / Face ID где поддерживается).
- Блокировка устройства: включение/выключение, повтор PIN, подсказка про биометрию.
- Сохранение ключей после закрытия браузера (опция): плюсы и минусы с точки зрения безопасности.

### 5.3 Резервное копирование и восстановление ключей
- Резервная копия ключей: установка пароля резервной копии (только для восстановления на новом устройстве).
- Восстановление на новом устройстве: ввод пароля резервной копии; при отсутствии ключей — предложение «восстановить» или «пропустить (новые ключи)».
- Ограничения при частых неудачных попытках восстановления.

### 5.4 Алгоритмы
- Упоминание поддержки алгоритмов (в т.ч. ГОСТ при наличии конфигурации) без технических деталей; при необходимости — ссылка на техническую документацию (например, e2ee-key-mechanism.html, e2ee-verify-gost-blackbox.md).

## 6. Уведомления и фоновые обновления

### 6.1 Push-уведомления
- Запрос разрешения в браузере.
- Условия: HTTPS (или localhost), поддержка Service Worker и Notification API.
- Типичные проблемы: «не поддерживается», «доступ запрещён», блокировка в Edge (исключения сайта).
- Связь с настройкой уведомлений в профиле и по беседам (вкл/выкл уведомлений по беседе).

### 6.2 Обновление чатов в реальном времени
- WebSocket: получение новых сообщений, реакций, статусов звонков без перезагрузки.
- Polling: режим «по запросу», когда WebSocket недоступен (кратко — что пользователь может заметить: задержки обновлений).

## 7. Дополнительные возможности интерфейса

### 7.1 Язык и локализация
- Выбор языка в настройках (если в приложении переключатель).

### 7.2 Эмодзи и стикеры
- Панель эмодзи: категории, поиск по ключевым словам, сортировка по использованию.
- Панель стикеров: категории, выбор стикера для отправки.
- Сохранение изображения/стикера «в стикеры» из контекстного меню сообщения.

### 7.3 Жесты и удобство
- Прокрутка к непрочитанному при открытии чата.
- Кнопка «прокрутить вниз» при длинной ленте.
- Переход к сообщению по ссылке (reply / «к сообщению» у звонка).

### 7.4 Профиль собеседника
- Просмотр профиля участника из чата: аватар, имя, статус, последняя активность (last seen).
- Открытие профиля из контекста сообщения.

---

## 8. Ограничения и известные особенности

- Внешний звонок: только аудио/видео, без переписки.
- Удаление сообщений: только свои.
- Удаление беседы «для всех» — необратимо для всех участников.
- Стикеры: загрузка только для администраторов (если так настроено).
- Запись звонка сохраняется на устройство того, кто записывает.
- Требования к браузеру: поддержка WebRTC, современных API для медиа и (для push) Service Worker и уведомлений.

## Порядок написания и структура файлов

Рекомендуемая структура:

1. **README или оглавление** — краткое описание приложения и ссылки на разделы.
2. **Один общий файл** (например, `USER_GUIDE.md`) с разделами 1–8, **или**
3. **Отдельные файлы по областям**, например:
   - `user-guide-account.md` — разделы 1–2;
   - `user-guide-chat.md` — раздел 3;
   - `user-guide-calls.md` — раздел 4;
   - `user-guide-privacy-e2ee.md` — раздел 5;
   - `user-guide-notifications.md` — раздел 6;
   - `user-guide-interface.md` — разделы 7–8.

При написании каждого подраздела:
- Описать **что** делает пользователь (шаги) и **что** он видит в интерфейсе.
- Указать ограничения и предупреждения (необратимость, только свои сообщения и т.д.).
- При необходимости давать ссылки на техническую документацию (E2EE, звонки, WebSocket), не дублируя её.
