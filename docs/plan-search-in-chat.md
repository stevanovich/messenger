# План: поиск текста сообщений в переписке

## Понимание задачи

Добавить возможность искать текст по сообщениям **внутри открытой переписки**: пользователь вводит запрос, приложение находит совпадения в тексте сообщений и позволяет переходить по ним (предыдущее/следующее) с подсветкой.

---

## Текущее состояние

- Сообщения отображаются в `#chatMessages` (`.chat-messages`).
- Каждое сообщение — блок `.message` с `.message-bubble` и `.message-content` (текст может быть HTML после `linkifyHtml(parseTextStyles(...))`).
- Есть `data-content-preview` на `.message` — краткий текстовый превью (для ответов).
- Сообщения подгружаются постранично через `api/messages.php?conversation_id=&last_message_id=&limit=50`; на клиенте полный список сообщений в памяти не хранится — только в DOM.
- Чаты и контакты уже имеют поиск (фильтр по списку); поиска по тексту сообщений в переписке нет.
- Поддерживается E2EE: контент на сервере может быть зашифрован, на клиенте отображается расшифрованный текст.

---

## Варианты реализации

### Вариант A: только клиентский поиск (рекомендуется для первого этапа)

- **Область поиска:** только сообщения, уже загруженные в текущем чате (видимые в DOM).
- **Плюсы:** не требует изменений API и БД, работает с E2EE (ищем по уже расшифрованному тексту в DOM), быстрая реализация.
- **Минусы:** нельзя найти текст в сообщениях, которые ещё не подгружены (например, старые сообщения сверху).

### Вариант B: серверный поиск (опционально, позже)

- **Область поиска:** все сообщения беседы в БД.
- **Ограничение:** при E2EE контент в БД зашифрован — полнотекстовый поиск по серверу без расшифровки невозможен. Имеет смысл только для **незашифрованных** чатов.
- Реализация: добавить в `api/messages.php` параметр `q` и условие `WHERE content LIKE ?` / полнотекстовый индекс по `content`; возвращать список сообщений с пагинацией; на клиенте показывать результаты и переходить к сообщению (при необходимости подгружать контекст).

---

## План реализации (Вариант A — клиентский поиск)

### 1. UI

- **Размещение:** панель поиска внутри области чата, например:
  - под шапкой чата (`#chatHeader`) или над лентой сообщений (`.chat-messages-wrap`), или
  - в шапке чата как иконка «лупа», по клику раскрывается строка поиска (как во многих мессенджерах).
- **Элементы:**
  - поле ввода (например `#chatSearchInput`);
  - кнопки «Предыдущее» / «Следующее» (или стрелки вверх/вниз);
  - счётчик «N из M» (опционально);
  - кнопка закрытия поиска.
- Панель видна только когда открыт чат; при смене беседы или закрытии чата — скрывать и сбрасывать поиск.

**Файлы:** `index.php` (разметка), при необходимости `includes/footer.php` (локализация).

### 2. Локализация

- Добавить ключи в `locale/*.php`, например:
  - плейсхолдер поля: «Поиск в чате» / "Search in chat";
  - «Предыдущее» / «Следующее», «Закрыть поиск», «Ничего не найдено», «N из M».
- Пробросить их в JS через `window.__LANG__` или существующий механизм (как для `chat.scroll_to_bottom` и т.п.).

**Файлы:** `locale/ru.php`, `locale/en.php`, `locale/sr.php`, `includes/footer.php`.

### 3. Логика поиска (JavaScript)

- **Источник текста:** искать по тексту из `.message-content` (для точности — `textContent`, чтобы не учитывать разметку). Учитывать только сообщения с текстовым контентом (тип `text` или наличие текста в пузыре), при желании — также превью звонков и подписи (если есть) из того же блока.
- **Алгоритм:**
  - при изменении поля поиска (debounce опционально, 150–300 ms) собрать все `.message` в `#chatMessages`;
  - для каждого взять `.message-content` и проверить вхождение запроса (регистронезависимо или с опцией «с учётом регистра» — можно отложить);
  - запомнить список совпадающих элементов (или их `data-message-id`) и текущий индекс «выбранного» совпадения.
- **Подсветка:**
  - в каждом `.message-content` подсветить вхождения запроса (например, обернуть в `<mark class="chat-search-highlight">`). Важно: содержимое `.message-content` — HTML; безопасный способ — обходить текстовые узлы (TreeWalker или рекурсия), находить подстроки, оборачивать в `<mark>`;
  - при смене запроса или закрытии поиска — снять все подсветки (удалить `<mark>`, вернуть исходный текст).
- **Навигация:**
  - «Следующее»: перейти к следующему совпадению в списке, прокрутить ленту так, чтобы сообщение было в зоне видимости (`scrollIntoView`), опционально выделить текущее сообщение (класс `chat-search-current`);
  - «Предыдущее»: аналогично к предыдущему;
  - при одном совпадении или нуле — кнопки отключить или показывать «0 из 0» / «Ничего не найдено».
- **Состояние:**
  - при открытии другой беседы или закрытии чата — очистить поле поиска, снять подсветку, скрыть панель поиска (если она привязана к окну чата).

**Файл:** `assets/js/chat.js`.

### 4. Стили

- Стили для:
  - панели поиска (расположение, отступы, кнопки);
  - `.chat-search-highlight` (подсветка вхождения, например жёлтый фон);
  - `.chat-search-current` (текущее выбранное сообщение при навигации — лёгкая рамка или фон).
- Учесть тёмную/светлую тему, если есть.

**Файл:** `assets/css/chat.css`.

### 5. Доступность и UX

- Клавиатура: по возможности при фокусе в поле поиска обрабатывать Enter как «следующее», Shift+Enter — «предыдущее»; Escape — закрыть поиск и снять подсветку.
- ARIA: подписать поле (label), кнопки (aria-label), при необходимости живой регион для «N из M» и «Ничего не найдено».

### 6. Ограничения (клиентский поиск)

- Поиск только по уже загруженным сообщениям. При необходимости в будущем можно добавить подсказку: «Показаны результаты только по загруженным сообщениям. Загрузите старые сообщения, прокрутив вверх».
- Не ищем по медиа (картинки/стикеры/файлы) — только по тексту в `.message-content` и при желании по превью звонков.

---

## Порядок работ (краткий)

1. Разметка: панель поиска в окне чата + id для поля и кнопок.
2. Локализация: ключи и вывод в шаблон/JS.
3. JS: сбор совпадений по `.message` в `#chatMessages`, подсветка в `.message-content`, навигация предыдущее/следующее, скролл к сообщению, сброс при смене чата.
4. CSS: оформление панели и подсветки.
5. Проверка: смена чата, пустой запрос, один/несколько результатов, Escape/Enter.

## Опционально (позже)

- **Серверный поиск** для незашифрованных чатов: параметр `q` в `api/messages.php`, пагинация по результатам, отображение списка «найденных сообщений» и переход к выбранному (с подгрузкой контекста).
- Опция «с учётом регистра».
- Поиск по дате или по типу сообщения (только текст / только звонки и т.д.) — при необходимости.

## Принятые решения

1. **Размещение:** в шапке чата — иконка лупы, по клику раскрывается строка поиска.
2. **Функциональность:** подсветка совпадений + кнопки «Предыдущее»/«Следующее» + счётчик «N из M».
3. **Серверный поиск:** планируется; в API можно заложить параметр `q` для незашифрованных чатов.
