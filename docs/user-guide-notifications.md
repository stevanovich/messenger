# Уведомления и обновления

Раздел описывает push-уведомления о новых сообщениях и обновление чатов в реальном времени (WebSocket и режим по запросу).

---

## 6.1 Push-уведомления

**Назначение**

- Push-уведомления показывают новые входящие сообщения, когда вкладка с Messenger не активна или браузер свёрнут. Настройка выполняется в профиле (см. [Учётная запись и настройки](user-guide-account.md)) и при необходимости по отдельным беседам (вкл/выкл уведомлений по чату).

**Разрешение в браузере**

- При первом включении уведомлений в настройках приложение запрашивает у браузера разрешение на показ уведомлений. Необходимо выбрать «Разрешить» (или аналог в диалоге браузера). При отказе уведомления работать не будут; разрешение можно изменить позже в настройках сайта в браузере.

**Условия работы**

- **HTTPS** — push-уведомления работают только при открытии сайта по защищённому протоколу (https). На localhost они также обычно доступны для разработки.
- Браузер должен поддерживать **Service Worker** и **Notification API**. Старые браузеры или режимы без поддержки этих API не поддерживают push; приложение может показать сообщение «Не поддерживается в этом браузере».

**Типичные проблемы**

- **«Уведомления не настроены на сервере»** — на сервере не заданы ключи VAPID для push. Обратитесь к администратору.
- **«Доступ запрещён»** — пользователь отклонил запрос разрешения или отключил уведомления для сайта в настройках браузера. Включите уведомления для этого сайта в настройках (например, «Настройки → Сайты → Уведомления»).
- **Браузер блокирует подписку** — в Microsoft Edge при включённой «Защите от отслеживания» подписка на push может блокироваться. Добавьте сайт Messenger в исключения: «Настройки → Конфиденциальность → Защита от отслеживания» и укажите сайт в списке исключений.
- **«Уведомления работают только по HTTPS»** — откройте сайт по адресу https://… вместо http://.

**Связь с настройками по беседам**

- В информации о беседе можно отключить уведомления только для этой беседы (остальные продолжат присылать push). Это не отменяет общее разрешение в браузере — отключается только отправка уведомлений по выбранному чату.

## 6.2 Обновление чатов в реальном времени

**WebSocket**

- При нормальной работе приложение держит постоянное соединение с сервером (WebSocket). По нему приходят новые сообщения, реакции, статусы доставки и прочтения, события звонков без перезагрузки страницы и без необходимости обновлять чат вручную. Список чатов и счётчики непрочитанных обновляются автоматически.

**Режим «по запросу» (polling)**

- Если WebSocket недоступен (ограничения сети, файрвол, сервер не поддерживает или отключён), приложение переключается на режим обновления **по запросу**: данные запрашиваются у сервера при переключении между чатами, при открытии приложения или периодически. В настройках может отображаться подпись вроде «Обновления по запросу» (polling).
- **Что заметит пользователь:** новые сообщения и изменения могут появляться с задержкой до следующего запроса; список чатов и счётчики обновляются не так мгновенно, как при WebSocket. Для актуального состояния можно переключиться в другой чат и обратно или обновить страницу.
