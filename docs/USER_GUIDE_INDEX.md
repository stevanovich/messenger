# Руководство пользователя Messenger

Messenger — веб-приложение для обмена сообщениями, голосовых и видеозвонков с поддержкой групповых чатов, сквозного шифрования (E2EE) и уведомлений.

Документация разбита по областям. Выберите нужный раздел:

| Раздел | Описание |
|--------|----------|
| [Учётная запись и настройки](user-guide-account.md) | Регистрация, вход, выход, профиль, аутентификация, уведомления, удаление данных |
| [Переписка](user-guide-chat.md) | Чаты и группы, отправка сообщений, реакции, прочтения, управление беседами, приглашения по ссылке |
| [Звонки](user-guide-calls.md) | Звонки 1-на-1, групповые и внешние звонки, присоединение по ссылке, запись, демонстрация экрана |
| [Конфиденциальность и E2EE](user-guide-privacy-e2ee.md) | Сквозное шифрование, разблокировка по PIN/биометрии, резервная копия и восстановление ключей |
| [Уведомления и обновления](user-guide-notifications.md) | Push-уведомления, обновление чатов в реальном времени (WebSocket и polling) |
| [Интерфейс и ограничения](user-guide-interface.md) | Язык, эмодзи и стикеры, удобство использования, профиль собеседника, ограничения приложения |
